#**Jogo da Void**

Trabalho Prático – Etapa 1 · Programação II (2026/2) Universidade Federal do Espírito Santo · Departamento de Informática

**Autor:** Daniel Schwartz Cantarella

###**Sobre o projeto**

O Jogo da Void é um protótipo simplificado de jogo de tabuleiro digital, escrito em C. N jogadores disputam uma corrida por uma trilha linear de células, cada uma com uma ação própria. Vence o primeiro jogador que alcançar o Fim do mapa.
